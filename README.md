# Learning

Learning is an iOS app that helps you build a daily learning habit. Set a goal for a week, a month, or a year and track your progress one day at a time.

## Main Features

- Create or update a weekly, monthly, or yearly learning goal.
- Log a day as learned or use a freeze to keep your streak going. A frozen day preserves the streak without increasing it.
- Track your learning streak and see how many freezes you have used. The streak resets after **more than 32 hours** without logging a day as learned or using a freeze. Each new goal starts with a streak of zero.
- Browse past learning and freeze entries in a yearly calendar.
- See whether you reached your goal when its duration ends. The goal is complete when every day in its duration is marked as learned or frozen.
- Resume your goal and daily activity after reopening the app.

## Technologies

- **Swift** for data models and application logic.
- **SwiftUI** and **Liquid Glass** for the interface.
- **MVVM** to organize models, views, and view models.
- **UserDefaults** and **Codable** for local persistence.
- **Sketch** for interface design.
